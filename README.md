# Collection Manipulator

## 📌 Project Description

The **Student Data Organizer** is a simple Python console-based project used to manage student information.

This project allows users to:
- Add student information
- Display all students
- Update student information
- Delete student information
- Display all subjects offered
- Exit the program

## 🛠️ Concepts Used

- Python Lists
- Python Sets
- Python Dictionaries
- Tuples
- `if-elif-else` conditions
- `while` loop
- `for` loop
- User Input
- String `split()` method
- `break` and `else` with loops

## 📋 Student Information

The program stores:

- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects

The combination of **Student ID and Date of Birth** is stored as a tuple in `unique_info`.
